# MRIME optimization experiments

MATLAB implementations, comparison algorithms, and CEC benchmark data for numerical optimization.

## Getting started

Open this directory as MATLAB's current folder. Build the benchmark functions with a configured C++ MEX compiler:

```matlab
mex -setup C++
mex cec17_func.cpp
mex cec22_func.cpp
```

The original scripts target Windows paths. On other systems, adapt backslash paths with `fullfile`; the MEX sources may also require platform-specific compiler adjustments. Prebuilt binaries are not included.

- `MRIME_RL_Cov.m`: optimizer used by the main comparison scripts.
- `Run_CEC2017_total_MRIME.m` and `Run_CEC2022_total_MRIME.m`: benchmark comparisons.
- `Run_CEC2017_Strategy_MRIME.m` and `Run_CEC2022_Strategy_MRIME.m`: strategy comparisons.
- `input_data/` and `input_data22/`: benchmark matrices, shifts, permutations, and seeds.

Review `run`, `dim`, and the evaluation budget before starting: the supplied scripts use 51 independent runs. They use `parfor` and statistics functions, requiring the corresponding MATLAB toolboxes; optimizer variants also call `normr`. Plotting and statistics scripts may expect result `.mat` files generated by the experiments. Saved results and rendered figures are not included.

Source files and benchmark data are preserved from the supplied archive. Execution has not been validated in MATLAB. Original author and third-party notices remain in the source; the archive's RDGMVO attribution is retained in [this note](docs/third-party/rdgmvo-original-readme.md).

# Research code

Code for research projects on optimisation, wireless sensing and communication, language
models, 3D vision and AI for science. Every project lives in its own repository with
installation instructions, data, tests, and the commands for its experiments.

Homepage: [odurshi.com](https://odurshi.com)

| Project | Topic | Repository |
|---|---|---|
| MRIME-CD | Modified RIME optimiser with covariance learning and diversity enhancement ([Cluster Computing, 2025](https://doi.org/10.1007/s10586-025-05348-3)) | [mrime](https://github.com/OdurShi/mrime) |
| EDECO | Educational competition optimiser with an estimation-of-distribution framework and dynamic fitness-distance balancing ([Biomimetics, 2025](https://doi.org/10.3390/biomimetics10030176)) | [edeco](https://github.com/OdurShi/edeco) |
| Cell-free ISAC AP deployment | Reinforcement-learning access point deployment for localisation accuracy and communication rate ([ISAC workshop at ACM MobiCom '24](https://doi.org/10.1145/3636534.3698221)) | [cell-free-isac-ap-deployment](https://github.com/OdurShi/cell-free-isac-ap-deployment) |
| Cell-free ISAC multi-agent placement and operation | Ray-traced ISAC simulator (Sionna RT), access point placement as a team game, and per-access-point mode selection for aerial targets behind buildings, compared with centralised optimisers | [cell-free-isac-multiagent](https://github.com/OdurShi/cell-free-isac-multiagent) |
| SBLS | Sequential label-space selection for open-world classification (AAAI 2027) | [sbls](https://github.com/OdurShi/sbls) |
| QCV | Question-code verification for visual question answering (AAAI 2027) | [qcv](https://github.com/OdurShi/qcv) |
| SIGMA | Label-efficient adaptation to changing task guidance | [sigma](https://github.com/OdurShi/sigma) |
| VD-OPD | View-decomposed on-policy distillation | [vd-opd](https://github.com/OdurShi/vd-opd) |
| 4DReSplat | Reasoning segmentation in dynamic Gaussian scenes | [4dresplat](https://github.com/OdurShi/4dresplat) |
| Scientific evidence agent | Tool-calling agent that answers chemistry and biology questions from public databases and checks every cited identifier against the archived responses | [sci-evidence-agent](https://github.com/OdurShi/sci-evidence-agent) |
| Perturbation baseline gate | Simple baselines and an acceptance test for models that predict the transcriptional response to genetic perturbations | [perturbation-baseline-gate](https://github.com/OdurShi/perturbation-baseline-gate) |

The projects are maintained in the separate repositories above. Earlier source snapshots remain
in `projects/` for existing links.
